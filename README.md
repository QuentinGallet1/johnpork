# Voici la liste complète des commandes disponibles.

---

## 💰 **Commandes Économie**

### `!porklards` (alias: `!p`)
Affiche ton solde de porklards. Utilise `!p @mention` pour voir celui de quelqu'un d'autre.
```
!porklards
!p @User
```

### `!give @User <montant>`
Donne des porklards à un autre utilisateur.
```
!give @User 100
```

### `!gamble [montant]` (alias: `!g`)
Lance un jeu de hasard. Par défaut 10 porklards, tu peux parier plus.
```
!gamble
!gamble 50
```

### `!russian_roulette @User <montant>` (alias: `!rr`)
Jeu à la roulette russe contre un utilisateur. Le perdant perd le montant, le gagnant le gagne.
```
!russian_roulette @User 50
```

### `!shop` (alias: `!s`)
Affiche le magasin des items disponibles à l'achat.
```
!shop
```

---

## 🎮 **Commandes Jeux**

### `!blackjack [montant]` (alias: `!bj`)
Joue au blackjack. Par défaut 10 porklards.
```
!blackjack
!blackjack 100
```

### `!enter_dungeon` (alias: `!ed`)
Entre dans la maison de John Pork. Affrontez les ennemis et récupérez du butin !
```
!enter_dungeon
```

---

## 🏎️ **Commandes Courses**

### `!join_team <nom_equipe>` (alias: `!Rjt`)
Rejoins une équipe ou crée-la si elle n'existe pas.
```
!join_team Equipe_Rouge
```

### `!start_race` (alias: `!Rsr`)
Lance une course avec toutes les équipes.
```
!start_race
```

### `!show_team` (alias: `!Rst`)
Affiche les équipes et leurs pilotes.
```
!show_team
```

### `!race_shop` (alias: `!Rs`)
Magasin de sport automobile pour améliorer ta voiture.
```
!race_shop
```

---

## 🎒 **Commandes Inventaire**

### `!inventory [mention]` (alias: `!i`)
Affiche ton inventaire. Ajoute une @mention pour voir celui de quelqu'un d'autre.
```
!inventory
!inventory @User
```

### `!use_item <nom_item>` (alias: `!ui`)
Utilise un item de ton inventaire.
```
!use_item Baril de foutre
```

---

## 📊 **Commandes Classement**

### `!classement [nombre]` (alias: `!c`, `!lb`)
Affiche le classement des porklards. Par défaut top 10.
```
!classement
!classement 20
```

---

## 💳 **Commandes Dettes**

### `!lend_money @User <montant> [intérêt]` (alias: `!lm`)
Endette quelqu'un pour une semaine. L'intérêt par défaut est 100 (100%).
```
!lend_money @User 100
!lend_money @User 100 50
```

### `!show_debt [@User]` (alias: `!sd`)
Affiche les dettes. Ajoute une @mention pour voir les dettes d'une personne.
```
!show_debt
!show_debt @User
```

### `!refund_debt @User` (alias: `!rd`)
Rembourse ta dette envers un utilisateur.
```
!refund_debt @User
```

### `!check_daily`
Vérifie si tu as reçu ta récompense quotidienne.
```
!check_daily
```

---

## 📝 **Notes**

- Les alias sont des raccourcis pour les commandes. Par exemple `!i` au lieu de `!inventory`
- Les commandes avec `[paramètre]` sont optionnelles
- Les commandes avec `<paramètre>` sont obligatoires
- Les porklards 💰 sont la monnaie du serveur
